# Skills

Repo portatil de skills para copiar a otros repos segun necesidad.

## Para que sirve

- Mantener una base curada de skills reutilizables.
- Llevarte skills entre repos, PCs o contextos de trabajo.
- Tener un diccionario simple de que hace cada skill antes de copiarlo.

## Que se versiona

- `skills/`: skills activos y listos para reutilizar.
- `templates/`: plantilla base para skills nuevos.
- `catalog/skills-dictionary.md`: diccionario resumido de skills.

El resto del material operativo queda fuera del repo publicado.

## Como usarlo

1. Revisa el diccionario en `catalog/skills-dictionary.md`.
2. Copia el skill que necesites desde `skills/<skill-name>/`.
3. Adaptalo al repo destino si hace falta.
